# Kali Launcher

GTK 3 desktop app to browse and run Kali tools (Docker containers or the host) in embedded terminal tabs.
Search, per-tool info and usage, favorites/recents, session logs, graphical-app setup, and a target/scope guard.

Only test systems you own or have written permission to test.

    sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-vte-2.91
    python3 kali_launcher.py
